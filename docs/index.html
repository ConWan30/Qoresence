Qoresence

A local-first operations console for gamers and streamers. The capture card is the brain: PS5 HDMI + DualSense HID + vision + situation model are turned into one causal timeline, then exposed through read-only glasses — Deck, Monitor, ClutchBot, AgentGlass, MCP, and Foundry RAG.

GitHub Wiki Discussions Roadmap

One brain → N glasses

Event bus + situation once. Lens, Theater, Monitor, Twitch, AgentGlass, and MCP are views — not duplicate engines.

Qoresence owns the card

Pattern B: the physical HDMI capture card stays with Qoresence. OBS uses Browser Source only. No dual-open DShow.

FrameHub · no second capture

Streamer publishes BGR frames it already holds. Monitor and IVC subscribe only.

Input–Video Coupler

HID edges join frame clock_ns / seq for co-occurrence coupling — observation only.

AgentGlass + MCP new

Any AI agent (Cursor, Claude, etc.) can query the timeline over 127.0.0.1:8765 without opening the capture card.

Foundry RAG new

Search past clips by chapter, buttons, DriveGraph, and timeline — no capture needed. Ask "show me red-zone pressure."

Streamr experimental

Optional DePIN publishing. Default OFF; only considered after the local plane is proven stable.

python -m qoresence.cli --play --deck --monitor --agent-glass --streamer-fps 30
