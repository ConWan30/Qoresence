The surface

One session.
Many useful views.

Qoresence is not another dashboard glued onto a capture card. It is a local event plane with purpose-built glasses for operators, viewers and agents.

GLASS / 01

Deck

Live theater, rail and OBS browser source from the same frames the streamer already owns.

GLASS / 02

Situation

Scores, down, clock, pressure and moments — with blank-frame guards that prefer uncertainty over invented facts.

GLASS / 03

Foundry

Local MP4 clips, chapter sidecars and drive memory become searchable session evidence after the match.

GLASS / 04

ClutchBot

Fast video-plus-input energy can meet slower OCR confirmation before chat gets a factual call.

GLASS / 05

AgentGlass

A read-only spectator boundary for external agents. No second capture, no hidden write path, localhost by default.

GLASS / 06

MCP

Snapshot, events, health, frame, clips, situation, search, graph, subscribe and freeze diagnosis over stdio.

The architecture

Capture once.
Subscribe everywhere.

The hard rule is simple: one physical device, one owner. Every other surface consumes the causal bus or FrameHub.

Install the local plane.

Download the Windows starter package, run the installer once, then launch the pilot. Python 3.11+ is required; capture hardware is optional for setup and required for live frames.
