Qoresence

Local game presence engine: HDMI / OBS Virtual Cam + DualSense HID + situation model, rendered through Retina Deck, native FrameHub monitor, Foundry clips, and optional ClutchBot — without dual-opening the capture card or claiming truth-plane legitimacy.

One brain → N glasses

Event bus + situation once. Lens, Theater, Monitor, and Twitch panel are views — not duplicate engines.

OBS owns the card

Physical HDMI stays with OBS. Qoresence consumes Virtual Camera. Preview remains the low-lag eye.

FrameHub · no second capture

Streamer publishes BGR frames it already holds. Monitor and IVC subscribe only.

Input–Video Coupler

HID edges join frame clock_ns / seq for co-occurrence coupling — observation only.
