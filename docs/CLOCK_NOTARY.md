# Clock Notary v0 (compose)

Qoresence remains the eyes. QorTroller becomes the notary of the same clock, after the gamer says so.

This is an **observation-plane** landing of the compose pack. It does not enable PoEP, does not write chain, and does not light the TRUTH glyph.

## In this repo

- Package: `qoresence/compose/clock_notary/`
- Export helper: `qoresence/observation/clock_notary_export.py`
- Tests: `tests/test_clock_notary.py`

## Commands

```powershell
python -m qoresence.compose.clock_notary.cli export --recap recap.json --out observation-envelope.json
```

Wrap is **out of plane**. Run it in QorTroller (`scripts/clock_notary_wrap.py`) with a gamer-signed consent file. `signed_by=bridge` is refused.
