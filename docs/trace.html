A Qoresence-styled reader for Jaeger traces. Open any trace ID from an .otel.json sidecar and browse the spans by clock, lobe, and event type.

Hint: when served from Retina Deck, the base URL is automatically proxied through /api/jaeger. Truncated IDs like 3a5ecc will 404 — use the full 32-character trace ID from .otel.json.
