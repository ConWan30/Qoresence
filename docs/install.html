Three steps

Unzip. Install. Launch.

The installer does not hide the Python environment or silently turn on cloud integrations.

Step / 01

Unzip

Extract to a folder you own, for example C:\Qoresence. Avoid a protected system directory.

Step / 02

Install

Run from the package folder.

powershell -ExecutionPolicy Bypass -File .\Install-Qoresence.ps1
Step / 03

Launch

Connect the card when you are ready, then start the local Deck.

.\Start-Qoresence.bat
Package

What ships. What does not.

Included

  • Qoresence source and command-line launcher
  • Deck, Session Theater, Monitor, AgentGlass, MCP adapter
  • Windows installer and pilot launcher
  • Profiles, examples, and operational docs

Not bundled

  • Capture-card drivers or vendor firmware
  • API keys or other secrets
  • Optional OCR stacks
  • OBS itself — Lens is a Browser Source if you use it
  • A signed native EXE; this release is transparent Python
Hardware rule: one physical HDMI/DShow device gets one owner. Close OBS on the physical card before --play. Phone glass is /mobile.html on localhost. Same-Wi-Fi bind is opt-in, not the default.
