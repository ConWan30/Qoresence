Essay / observation plane

The overlay that would rather go dark.

Qoresence is a local-first Gaming Streaming Observatory Engine. It is not an AI coach, not anti-cheat, and not a second copy of your capture card.

One clock

PS5 HDMI (capture card), DualSense HID, and game situation share one monotonic clock (clock_ns / frame_seq). The capture card is the brain. Everything else is a glass: Retina Deck, Clutch Lens (OBS Browser Source), Mobile Glass, Foundry clips, AgentGlass / MCP.

OBS never owns the physical card in the recommended path. It loads overlay.html as a Browser Source. Dual-opening USB3.0 Video is how LIVE dies.

Fail-closed is the brand

Most stream overlays keep the last score on screen through pause, menu, and a frozen JPEG. That looks smooth. It is a lie.

Qoresence paints widgets only when they match the LIVE frame (Same-Seq). If title-presence is not play, or the frame is blank, Theater goes dark. Empty glyphs (□–□) are honest. Invented 0-0 is not.

Digits on the board require a confirm / VLM lock. The fast path may talk clutch. It does not invent a score.

What we will not say

Language is co-occurrence, coupling, presence evidence. Not legitimacy, humanity, eligibility, or “you threw that.” There is no live path into QorTroller / PoAC / *-truth.
