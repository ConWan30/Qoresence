Same three frozen tools. Wire numbers unchanged. Tags are operator speech only. Each tag has one shape and one color, so it reads at a glance and in grayscale.

Tools: gate.run · gate.status · gate.get_result. Auth header name only: X-Api-Key (bring your own; never paste keys into Pages).

The rule, drawn

One key. Three answers.

The whole door is a lookup on two questions: has this idempotency_key been lodged, and does the payload match? This is the frozen behavior, not measured traffic.

Ways to knock

Every path reaches the same three tools.

HTTP, MCP, a share-sheet link, or a Qoresence commit. No fourth tool and no new GateResult fields on any path.

/v1/gate/*

HTTP REST

POST /v1/gate/run, then status and result by job_id. Header X-Api-Key; the key is yours and never on this page.

vibegate-mcp

MCP over stdio

Same three tools for Cursor, Claude Code, Codex, and Grok Build. Shared door, not a sandbox.

MCP over HTTPS

Optional and additive. JSON-RPC body isomorphic to stdio. Same X-Api-Key as REST.
