# Welcome

**Qoresence** is a local **observation-plane** engine for streamers and gamers:

- HDMI / **OBS Virtual Camera** frames  
- Optional **DualSense Edge** HID  
- **Situation model** + causal **event bus**  
- Glasses: **Retina Deck** (Lens + Theater), **native Retina Monitor**, Foundry clips  
- Optional **ClutchBot** for Twitch  

### Principles

1. Lobes default **OFF**  
2. One physical capture device → **one owner** (usually OBS)  
3. Language: **co-occurrence / coupling** — not anti-cheat or “proof of humanity”  
4. Shared `clock_ns` joins modalities — not Twitch delay
