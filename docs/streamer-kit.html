Streamer Kit · free · beta

Madden on OBS. Only scores it locked.

A free setup bundle for Madden 27 streamers who use OBS. Qoresence reads the scorebug from your HDMI capture card and drives OBS: it shows the score only once it is sure, saves a replay when the score goes up, and can flip a scene. When it is unsure, nothing happens.

What it does

Four things, all opt-in.

Everything here already ships in Qoresence on main. The kit just packages the OBS side.

Overlay

Verified score text

Sets an OBS text source to the score only while it is locked and the capture is live. No lock, blank read or stale frame: the text goes empty.

Replay

Auto replay on score lock

A locked score increase saves your OBS replay buffer (at most once every 20 s). Turn off with --obs-no-replay.

Scene

Scene switch

Optionally flashes a scene for a few seconds and switches back. If you change scenes yourself, it leaves you alone.

Feed

Signed truth feed

Optional --truth-feed: an append-only, hash-chained log of locked scores, signed with a local key, that anyone can check with scripts/verify_truth_feed.py.

You need

  • Windows PC
  • OBS Studio 28 or newer (WebSocket server built in, port 4455)
  • An HDMI capture card, used by Qoresence (not added to OBS)
  • Madden 27

It never

  • Shows a guessed score
  • Saves a replay on an unsure read or an unlock
  • Stores your OBS password in a file it ships
  • Loads into OBS as a plugin (it talks over the local WebSocket)
Setup

Five steps.

Full details in the bundle README and the OBS bridge doc.

01

Turn on WebSocket

OBS → Tools → WebSocket Server Settings. Enable it, keep port 4455, copy the password from Show Connect Info.

02

Import the scene

Scene Collection → Import → Qoresence_Streamer_Kit.scene.json. You get scene Qoresence Score with text Qoresence Score Text.

03

Start the replay buffer

Settings → Output → Replay Buffer: enable (20–30 s). Click Start Replay Buffer before you play.

04

Save the password

Set QORESENCE_OBS_PASSWORD, or put it on one line in %USERPROFILE%\.qoresence\obs_password.txt.

05

Launch

Install with pip install -e ".[obs]", copy qoresence-stream.cmd next to qoresence.bat, double-click.

Beta, honestly

  • A capture-freeze fix is still waiting on a live test.
  • Unsure reads trigger nothing: no text, no replay, no scene switch.
  • The scene file is checked in CI but has not been import-tested on every OBS version yet.
  • The truth feed has not been tested live yet; it is off unless you add --truth-feed.
FAQ

Short answers.

Is it free?

Yes. The kit and Qoresence are open source on GitHub.

Do I add my capture card to OBS?

No. Qoresence uses the card. In OBS, capture your display or game window instead. Adding the same card twice will fight over it.

Why is the text source not called "Qoresence Score"?

OBS does not allow a scene and a source with the same name. The scene is Qoresence Score, so the text is Qoresence Score Text, and the launcher tells Qoresence that with --obs-text-source.

What if OBS is closed?

Qoresence keeps running, logs one warning and retries in the background.

What does the truth feed prove?

That the listed scores are the ones Qoresence locked, in order, unedited. It is not anti-cheat and makes no claim about who was playing.

Mac or Linux?

Not supported for the kit. It is Windows-first.
