# Pages fonts (Aperture Glass)

Self-hosted `woff2` so GitHub Pages does not depend on a runtime Google Fonts
stylesheet. Same OFL-1.1 families as Retina Deck (`glass/src/fonts`).

| Family          | Weights (latin, normal) | Role                        |
| --------------- | ----------------------- | --------------------------- |
| Instrument Sans | 400 / 500 / 600         | Titles, chrome, body        |
| IBM Plex Mono   | 500 / 600               | Digits, HOLD speech, code   |

Do not hand-edit the binaries; re-copy from `glass/src/fonts` if updating.
